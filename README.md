# Game Performance Analyzer

Performance information such as CPU, GPU, RAM, and FPS during gameplay
It is a program for recording and analyzing.

## Features

- Measuring CPU usage
- Measuring GPU usage
- Measure RAM usage
- FPS record
- Save CSV data

## Installation

Download the program from Releases.
2. Extract the compression.
3. Run GamePerformanceAnalyzer.exe.

## Usage

After launching the program, if you press `Start Recording`
PC performance data is recorded automatically.
